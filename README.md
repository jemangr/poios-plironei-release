## 🔥 Τι κάνει;

* **🖐️ Όλοι δάχτυλο στην οθόνη (2–10 παίκτες):** Καφές, Σουβλάκια, Ποτά, Μήνυμα στην Πρώην, Οδηγός, Πρόκληση (20 έτοιμες ελληνικές κάρτες) ή Δικό σας στοίχημα.
* **⚡ Επικές Ανατροπές (Fake-Outs):** Κλειδώνει τον έναν με sub-bass χτύπημα… και μισό δευτερόλεπτο μετά σκάει κεραυνός που ρίχνει τον λογαριασμό στον διπλανό!
* **🤫 Κρυφή Ζαβολιά:** Μυστικά gestures (double-tap γωνίας / triple-tap στο `jemangr.app`) που οπλίζουν για 1 γύρο και σβήνουν αυτόματα.
* **📸 Κάρτα 9:16 για TikTok / IG Stories:** Αυτόματη δημιουργία 1080×1920 PNG με χάρτη δαχτύλων, ετυμηγορία και roast.
* **🔄 Έλεγχος για Νέα Έκδοση:** Η εφαρμογή ελέγχει αυτόματα & χειροκίνητα για νέες εκδόσεις APK απευθείας από εδώ.
* **🔒 100% Τοπικά &amp; Offline:** Χωρίς server, χωρίς λογαριασμό, χωρίς διαφημίσεις.
